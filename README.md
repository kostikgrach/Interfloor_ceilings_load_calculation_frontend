# ЛР5 — нагрузки на междуэтажные перекрытия

Гостевое SPA на React, TypeScript, Vite, React-Bootstrap и React Router. Оформление плитки и ленты повторяет шаблоны бэкенда: узкая область шириной до 420 px, двухколоночная плитка, зелёный слайдер и видеокарточка с параметрами поверх видео. Для демонстрации каталог использует четыре локальные mock-записи. Числовые значения служат примерами для лабораторной работы.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

Открыть адрес Vite из терминала. Команда `npm run build` проверяет типы и собирает приложение в `dist/`. Команда `npm run preview` запускает проверку этой сборки.

## Страницы

| Путь | Содержимое и действия |
|---|---|
| `/` | Плитка нагрузок. Двойной слайдер задаёт диапазон нормативной нагрузки от 0 до 500 кг/м² с шагом 10. «Найти» применяет выбранный диапазон. «Подробнее» открывает выбранную карточку. |
| `/feed`, `/feed/:id` | Лента с одной видеокарточкой. Без ID открывается первая запись. Круглая стрелка открывает следующую запись, после последней открывается первая. «Еще» разворачивает описание. |
| `/loads/:id` | Карточка с видео, описанием, нормативной нагрузкой и коэффициентом надёжности. Видеокарточка оформлена как в ленте. Круглая стрелка открывает следующую запись в ленте, нижняя вкладка «Плитка» возвращает к списку. |

Нижняя панель содержит «Лента», «Добавление», «Плитка» и «Вход». Гостю доступны «Лента» и «Плитка». При размещении сборки настройте сервер так, чтобы для прямых запросов к маршрутам приложения он отдавал `index.html`. Vite делает это при локальном запуске.

## Данные и медиа

Все карточки берутся из локального массива в `src/data.ts`. Изображения и видео лежат в `public/media`. При пустой или недоступной ссылке `LoadMedia.tsx` подставляет `default-load.webp` либо `default-load.mp4`. Для запуска достаточно Node.js и npm.
